# AI 品牌图标（LLM Icons）

把 AI / LLM 品牌 logo 插入思源笔记的插件。收录 **357 个品牌**，支持中文别名搜索（输入「豆包」「智谱」「通义」即可命中）。

两种用途：**插入到正文**（默认动作），或**设为文档图标**。

图标来自 [Lobe Icons](https://github.com/lobehub/lobe-icons)（MIT License）。

## 用法

入口是一个**四角星芒图标**，出现在三处，任选其一：

- **表情面板** —— 点文档图标打开表情面板，顶部那排图标里点星芒，**就地切换**到 AI 品牌图标，
  面板里自带搜索框，输入即筛（不弹新窗口）。**动作跟着打开方式走**：
  - 从**文档标题图标**打开 → 选中的图标**替换文档图标**
  - 从**正文插入表情**打开 → 选中的图标**插入到光标处**

- **底栏** —— 编辑器面包屑栏最左边的星芒（若主题把面包屑移到底部，就是底部那条胶囊的最左端）
- **顶栏** —— 右上角工具栏里的星芒
- **快捷键** —— `⌥⌘Y`（macOS）/ `Alt+Ctrl+Y`

另外右键点击文档标题左侧的图标，菜单里也有入口。

点开后是一个搜索面板：光标直接在搜索框，**输入即筛**，默认停在「常用」27 个高频品牌上。
输入品牌名后按**回车**或**点击图标**即可插入正文。

在搜索框输入品牌名（中英文都行），或用分类筛选：**全部 / 常用 / 模型 / 服务商 / 应用 / 中文品牌**。

- **左键点击卡片** —— 把图标插入到正文光标处
- **悬停后点右上角按钮** —— 设为当前文档的图标
- **右键卡片** —— 菜单里两种操作都能选

插入正文的图标会存到 `assets/llm-icons/`，随文档一起导出，不会出现断图。

## 实现说明

图标文件存放在 `data/emojis/llm-icons/`，与思源原生自定义表情同目录，因此：

- 随工作区同步，多设备可用
- 不写 `custom-icon` 之外的非标准属性，卸载插件后已设的图标仍然显示

插件采用**按需写入**：只有你实际选中的图标才会被复制到工作区，不会一次性塞入 357 个文件。
